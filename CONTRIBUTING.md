# Contributing

Thanks for helping make patterns better than a PDF.

## Before you start

- For changes to the format, open an issue in [`spec`](https://github.com/ptrnformat/spec) first so we can discuss it before you write anything.
- For bugs and small fixes in code or docs, a pull request is fine without an issue.

## Pull requests

- Keep each pull request to one change.
- A spec change needs matching schema updates and conformance files (valid and invalid examples) where they apply.
- Code changes need tests.

## License of contributions

By contributing, you agree that your contribution is licensed under the license of the repository it goes into:

- `spec`: specification text under CC BY 4.0, and schemas, registry and conformance files under CC0
- `ptrn-js`: Apache 2.0
- `website`: code under Apache 2.0, written content under CC BY 4.0

Only submit work you wrote or have the right to share.

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md). Report security problems privately, as described in [SECURITY.md](SECURITY.md).
