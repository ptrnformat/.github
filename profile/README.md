<p align="center">An open, community-owned file format for stitched-craft patterns.</p>

---

**PTRN** (`.ptrn`) is an open file format for crochet and knitting patterns, with cross-stitch, needlepoint and embroidery to follow. A designer publishes one file, and any app, website or shop that supports PTRN can open it, now and in the future. No PDFs to retype, and no pattern locked inside one platform.

PTRN uses the Craft Yarn Council's standard stitch abbreviations and symbols. It is not endorsed by the Craft Yarn Council.

Learn more at **[ptrnformat.org](https://ptrnformat.org)**.

## The format

| Repo | What it holds |
| --- | --- |
| [`spec`](https://github.com/ptrnformat/spec) | The `.ptrn` specification, schemas, stitch registry and open decisions |
| [`ptrn-js`](https://github.com/ptrnformat/ptrn-js) | JavaScript library for reading and writing `.ptrn` files |

## Free tools (planned)

| Repo | What it does |
| --- | --- |
| [`reader`](https://github.com/ptrnformat/reader) | View and print `.ptrn` patterns in the browser |
| [`writer`](https://github.com/ptrnformat/writer) | Create and edit `.ptrn` files without writing code |
| [`converter`](https://github.com/ptrnformat/converter) | Turn an existing pattern into a `.ptrn` file to finish in Writer |

## Get involved

PTRN is in draft, and now is the best time to shape it. Designers, guilds, app developers and pattern shops are all welcome.

- **Have a view on the format?** Open an issue in [`spec`](https://github.com/ptrnformat/spec/issues).
- **Representing a guild or organisation?** Email [hello@ptrnformat.org](mailto:hello@ptrnformat.org).
