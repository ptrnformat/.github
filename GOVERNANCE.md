# Governance

The PTRN Working Group maintains the PTRN file format (`.ptrn`) and its reference tools. This is the whole governance model for now. It will grow as the project does.

## Roles

- **Founding editor:** Josh Evensen. The editor makes final decisions on the specification and the standard stitch registry.
- **Contributors:** anyone who proposes a change, reports a problem, or sends a pull request.

## How decisions are made

1. Changes to the format start as an issue in [`spec`](https://github.com/ptrnformat/spec).
2. Discussion happens in public, on the issue.
3. The editor decides, and records the decision and the reasoning on the issue.
4. Breaking changes land only in a new major version of the format. Minor versions may only add optional fields.

## Trademark

Anyone may implement the PTRN format freely. The names "PTRN" and "PTRN Working Group", the `.ptrn` extension branding, and the logo and file icon belong to the Working Group. Software may say it reads or writes PTRN files. Only the Working Group's own releases may call themselves "official".

## Changing this document

The editor may amend it by pull request. The long-term intent is to move the format to a neutral foundation once there is enough community to support one, with community input on that move.
